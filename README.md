1️⃣ Clone o repositório:

2️⃣ Entre na pasta desejada:

cd Atividade_Faculdade/nome-da-pasta

3️⃣ Abra os arquivos HTML no navegador

Todos os projetos são estáticos, portanto não exigem servidor adicional.
