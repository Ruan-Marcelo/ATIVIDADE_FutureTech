Sobre o Projeto

Ruan é foda, ele criou esse projeto incrível para mostrar seus conhecimentos em JavaScript, HTML e CSS. O Animatrix V2 é um catálogo interativo de animes que oferece trailers, músicas, curiosidades e informações detalhadas sobre os animes mais populares. Com uma interface moderna e fácil de usar, o Animatrix V2 é o lugar perfeito para os fãs de anime explorarem e descobrirem novos títulos para assistir.
